## 1. 프로젝트 개요

### 1.1 PEO란
PEO(Peo)는 러닝 크루 커뮤니티로, 기존 HRC(Hanyang Running Crew)에서 리브랜딩한 프로젝트이다. 러닝이라는 공통 관심사를 기반으로 크루원들이 함께 성장하고 동기부여를 받을 수 있는 플랫폼을 목표로 한다.

### 1.2 비전
"알에서 부화하는 러너 캐릭터" — 뛰면 캐릭터가 성장하는 러닝 게이미피케이션 앱. 러닝 데이터를 기반으로 캐릭터가 알에서 부화하여 점진적으로 성장하며, 러너의 실제 능력치가 캐릭터에 반영되는 구조이다.

### 1.3 핵심 슬로건
"혼자 뛰지만, 혼자 두지 않는 크루"

### 1.4 현재 상태
- 1기: 회원 25명, 수동 데이터 입력 방식
- 2기: 5명 베타 테스트, Strava API 자동 동기화 테스트 중
- 웹앱: 정적 사이트 배포, GitHub → Netlify 자동 배포
- 데이터: Google 스프레드시트 기반 관리

## 4. 점수 체계 v4.0

**최종점수 Q = 스피드×0.3 + 지구력×0.25 + 롱런×0.15 + 꾸준함×0.2 + 케이던스/효율성×0.1**

### 4.1 스피드 (가중치 0.30)
```
MIN(MAX((11 - 페이스(분)) / 7.5 × 100, 0), 100)
페이스 3:30 = 100점, 11:00 = 0점
```

### 4.2 지구력 (가중치 0.25)
| 구간 | 점수 |
|---|---|
| 0~15km | 0→75점 (km × 4점) |
| 15~30km | 75→90점 |
| 30~50km | 90→100점 |

### 4.3 롱런 (가중치 0.15)
| 구간 | 점수 |
|---|---|
| 0km | 0점 |
| 15km | 70점 |
| 21km | 80점 |
| 42.195km | 100점 |

### 4.4 꾸준함 (가중치 0.20)
```
MIN(러닝일수 / 5 × 100, 100)   ← 2주 5일 이상 = 100점
```

### 4.5 케이던스/효율성 (가중치 0.10)
- **1기 (케이던스):** `(케이던스 - 120) / (180 - 120) × 100`  → 120spm=0점, 180spm=100점
- **2기 (효율성):** `(moving_time / elapsed_time - 0.8) / 0.2 × 100`  → 80%=0점, 100%=100점

## 5. LV 시스템

### 5.1 공식
```
LV = FLOOR(100 × (EXP / b)^p)
```

| 파라미터 | 값 | 설명 |
|---|---|---|
| b (난이도) | **54,000** | 5개 능력치 체계에 맞춘 난이도 파라미터 |
| p (감속 지수) | **0.72** | 레벨 상승 곡선의 감속 정도 |

### 5.2 LV 도달 목표 기간

| LV | 예상 기간 | 누적 EXP (약) | 비고 |
|---|---|---|---|
| LV 10 | ~2개월 | ~2,000 | 초기 동기부여 구간 |
| LV 30 | ~12개월 | ~18,000 | 1년 꾸준히 달린 러너 |
| LV 50 | ~24개월 | ~38,000 | 2년 이상 지속한 러너 |
| LV 100 | 이론상 도달 불가 | — | 무한 목표 |

### 5.3 EXP 적립 방식
- 시즌(2주)마다 5개 능력치 점수의 합이 EXP로 누적
- 2주 최대 500점, 평균 **250~350점**
- `총 EXP = 누적 지구력EXP + 스피드EXP + 꾸준함EXP + 케이던스EXP + 롱런EXP`
